# 毕业进度小管家服务器部署说明

## 一、正式地址

- 前端：`https://biyejindu.jinshengxu.com.cn/`
- 运营后台：`https://biyejindu.jinshengxu.com.cn/credit-admin.html`
- Java 服务仅监听：`127.0.0.1:4180`
- 原简历网站继续监听：`127.0.0.1:4174`

## 二、域名解析

在阿里云云解析 DNS 中，为 `jinshengxu.com.cn` 增加记录：

| 配置项 | 值 |
|---|---|
| 记录类型 | A |
| 主机记录 | biyejindu |
| 记录值 | 当前轻量服务器的公网 IPv4 |
| TTL | 默认值即可 |

等待解析生效后，在本地执行 `nslookup biyejindu.jinshengxu.com.cn`，确认返回当前服务器公网 IPv4。不要删除或修改 `@`、`www` 等简历网站已有记录。

## 三、上传与执行

1. 把整个部署压缩包上传到服务器，例如 `/home/admin/`。
2. 解压后进入目录。
3. 执行：

```bash
sudo bash install-biyejindu.sh
```

脚本会执行以下操作：

- 核验简历网站服务和 `4174` 端口；
- 安装 Java 21，但不修改 Node.js；
- 在没有 Swap 时创建 2 GiB Swap；
- 下载 Apache Tomcat 9.0.122 并校验 SHA-512；
- 创建独立的 `biyejindu` 系统账号；
- 以 `700 MiB` 服务内存上限运行；
- 只监听本机 `4180` 端口；
- 添加独立 Nginx 配置；
- 为新子域名申请独立 HTTPS 证书；
- 保留原简历网站配置和服务；
- 在终端显示后台管理密钥。

## 四、部署后检查

```bash
systemctl status biyejindu --no-pager
systemctl status xjs-portfolio --no-pager
ss -lntp | grep -E '4174|4180|:80|:443'
curl -I https://biyejindu.jinshengxu.com.cn/
curl -I https://jinshengxu.com.cn/
```

预期结果：

- `biyejindu` 和 `xjs-portfolio` 都是 `active (running)`；
- `4174` 与 `4180` 均只绑定 `127.0.0.1`；
- 公网只开放原有的 80、443、22；
- 两个域名均可通过 HTTPS 访问。

## 五、回滚

如果新网站出现异常，进入解压后的部署目录执行：

```bash
sudo bash rollback-biyejindu.sh
```

该脚本只停止新网站并撤销新域名入口，不删除业务数据、不删除证书、不撤销 Swap，也不修改简历网站。

## 六、以后更新网站

以后更新不要重复运行首次安装脚本。把新的 `student_system.war` 与 `update-biyejindu.sh` 放在同一目录，然后执行：

```bash
sudo bash update-biyejindu.sh
```

更新脚本采用以下隔离措施：

| 项目 | 简历网站 | 毕业进度小管家 |
|---|---|---|
| 系统服务 | `xjs-portfolio.service` | `biyejindu.service` |
| 本机端口 | `127.0.0.1:4174` | `127.0.0.1:4180` |
| 程序目录 | `/opt/xjs-portfolio` | `/opt/biyejindu`、`/var/lib/biyejindu` |
| Nginx 配置 | 原配置保持不变 | `/etc/nginx/conf.d/biyejindu.conf` |
| 更新动作 | 不重启、不改文件 | 仅原子替换 WAR 并重启自身 |

更新前后都会检查简历服务和 `4174` 端口。新版本在 `4180` 的健康检查失败时，会自动恢复旧 WAR 并再次启动毕业进度服务。更新脚本不运行 `nginx reload`，不会修改证书，也不会安装或升级 Node.js、Java、Tomcat。

由于服务器只有约 `1.6 GiB` 内存，不建议在同一时刻再启动第二套 Java 蓝绿实例；双 Java 实例的内存压力反而更可能波及简历网站。当前方案会让毕业进度站点在自身重启时短暂不可用，但简历网站持续运行，是这台轻量服务器上风险更低的方案。

## 七、管理密钥

首次部署成功后，终端会输出后台管理密钥。请立即保存到密码管理器。服务器中的密钥文件为：

```text
/etc/biyejindu/biyejindu.env
```

该文件权限为 `0640`，不要下载、公开或粘贴到聊天中。
