# 系统架构

## 生产访问链路

```text
手机或桌面浏览器
        │ HTTPS
        ▼
Nginx（域名、证书、限速、请求体限制）
        │ 仅转发公开白名单路由
        ▼
Tomcat 9（127.0.0.1:4180）
        │
        ├─ 单页前端与运营后台
        ├─ 培养方案和成绩文件安全解析
        ├─ 身份信息脱敏与 DeepSeek 二次核对
        ├─ 本地确定性学分归类与显式重算
        └─ 结构化方案、匿名运营数据与反馈
```

现有简历网站继续由独立系统服务监听 `127.0.0.1:4174`。两个网站使用不同域名、端口、系统用户、数据目录和 Nginx 配置，互不替换。

## 主要流程

1. 浏览器填写学校、专业和入学年级。
2. 浏览器计算培养方案文件指纹，优先查询服务器是否已有同版本方案。
3. 用户上传培养方案（未命中缓存时）和成绩文件。
4. 后端执行格式、大小、压缩包、文本和表格规模检查。
5. 后端提取板块要求和课程数据，移除姓名、学号、联系方式等身份信息。
6. 后端把脱敏原文片段、结构化课程字段和培养方案要求发送给 DeepSeek 强制二次核对；原文件不外发。
7. 页面返回可编辑结果。用户修改板块、要求学分、课程归属或课程学分后，旧结果标记为过期；点击“更新学分结果”统一重算所有汇总区域。
8. 学分数值由本地确定性规则计算，DeepSeek 只给出一致性核对意见，不直接决定毕业资格。
9. 素质课程按独立完成条件展示，不进入培养方案规定的 165 学分；原文存在矛盾或映射不确定时必须提示人工核对。

## 目录职责

| 目录 | 职责 | 是否进入公开仓库 |
|---|---|---|
| `src/main` | 生产源码与静态资源 | 是 |
| `src/test` | 自动化测试 | 是 |
| `deploy` | 安装、回滚和部署说明 | 是 |
| `docs` | 架构、安全、质量和交接资料 | 是 |
| `源文件` | 真实或半真实回归样例 | 否 |
| `target` | Maven 构建产物 | 否 |
| `logs`、`output` | 本地日志和视觉截图 | 否 |
| `.codex-backups`、`.playwright-cli` | 工具状态和备份 | 否 |

## 数据边界

- 成绩原文件仅在请求期间解析，不进入上传目录。
- 培养方案原文件不长期保存；仅保存文件指纹和结构化规则。
- 生产数据目录为 `/var/lib/biyejindu`，源码目录和运行数据分离。
- 后台初始密码保存在服务器环境文件中；修改后只保存单向哈希，不写入仓库或网页。
- DeepSeek API 密钥可由环境变量提供，也可在后台加密保存；接口响应只返回是否已配置，不回显密钥。
- DeepSeek 请求目标固定为官方接口，仅发送脱敏后的必要数据；人工修改后，原 AI 意见会标记为基于首次上传结果。
