# 项目文档导航

文档按“先理解、再部署、后验收”的顺序组织：

1. [`架构/系统架构.md`](架构/系统架构.md)：系统边界、请求流程和目录职责。
2. [`安全/生产安全与部署检查表.md`](安全/生产安全与部署检查表.md)：上传防护、资源限制和生产检查项。
3. [`质量/视觉与交互验收.md`](质量/视觉与交互验收.md)：桌面端、手机端和视觉验收记录。
4. [`handover/03-security-hardening.md`](handover/03-security-hardening.md)：安全加固交接记录。
5. [`../deploy/服务器部署说明.md`](../deploy/服务器部署说明.md)：服务器安装、隔离更新、域名和回滚说明。

本地私有材料位于根目录 `源文件/`，仅用于回归测试，已排除在公开仓库之外。

当前验证基线：38 项 Maven 测试、8 项前端计算回归、WAR 构建、本地 Tomcat HTTP 与真实成绩 ZIP 接口通过。当前版本的生产上传、HTTPS、资源压力、主动回滚与真实手机视觉验收仍需按对应清单执行。
